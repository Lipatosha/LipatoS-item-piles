# LipatoS - Item Piles

Модуль для **Foundry Virtual Tabletop 14**, основанный на Item Piles, для работы со стопками предметов, контейнерами, хранилищами, торговцами, обменом между игроками и валютой.

## Версия

**3.3.4-rub-fix47**

## Возможности

- позволяет размещать предметы на сцене и забирать их как добычу;
- поддерживает обычные стопки предметов, контейнеры, хранилища и торговцев;
- поддерживает передачу предметов и валюты между персонажами;
- содержит интерфейс торговли и обмена между игроками;
- сохраняет русскую локализацию и дополнительные русские подписи текущей рабочей сборки;
- использует доработанный тёмный и компактный интерфейс окон добычи, торговли, торговцев и хранилищ;
- отображает цены и валюту с отдельными иконками медных, серебряных и золотых монет;
- добавляет описание монет и удобное отображение их веса;
- содержит доработки интерфейса для редактирования валюты ГМ и работы с валютой в хранилищах;
- сохраняет все исправления и изменения рабочей сборки `3.3.4-rub-fix47`.

## Важно об ID модуля

Внутренний ID **намеренно сохранён `item-piles`**.

На этот ID завязаны настройки Item Piles, его API (`game.itempiles`), флаги документов, пути ресурсов и другие модули LipatoS. Изменение ID могло бы нарушить совместимость с уже существующим миром и интеграциями.

Поэтому репозиторий и видимое название относятся к линейке **LipatoS**, но технический ID остаётся `item-piles`.

Оригинальный Item Piles и эту сборку одновременно устанавливать не нужно — эта сборка заменяет его.

## Зависимости

Для работы требуются:

- **SocketLib**;
- **libWrapper**.

Для мира **D&D 5e** также рекомендуется **LipatoS - Item Piles: D&D 5e**. Foundry сможет предложить его установку автоматически. Адаптер добавляет системную интеграцию валюты, цен, контейнеров и предметов D&D5e.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-item-piles/main/module.json`
