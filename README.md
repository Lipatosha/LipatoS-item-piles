# LipatoS - Item Piles

Модуль для **Foundry Virtual Tabletop 14**, основанный на Item Piles, для работы со стопками предметов, контейнерами, хранилищами, торговцами, обменом между игроками и валютой.

## Версия

**3.3.7**

## Возможности

- позволяет размещать предметы на сцене и забирать их как добычу;
- поддерживает обычные стопки предметов, контейнеры, хранилища и торговцев;
- поддерживает передачу предметов и валюты между персонажами;
- содержит интерфейс торговли и обмена между игроками;
- сохраняет русскую локализацию и дополнительные русские подписи текущей рабочей сборки;
- использует доработанный тёмный и компактный интерфейс окон добычи, торговли, торговцев и хранилищ;
- отображает цены и валюту с отдельными иконками медных, серебряных и золотых монет;
- добавляет описание монет и удобное отображение их веса;
- содержит доработки интерфейса для редактирования валюты ГМ и работы с валютой в хранилищах;
- включает все исправления сборки `3.3.4-rub-fix51` и последующие обновления.

## Важно об ID модуля

Внутренний ID **намеренно сохранён `item-piles`**.

На этот ID завязаны настройки Item Piles, его API (`game.itempiles`), флаги документов, пути ресурсов и другие модули LipatoS. Изменение ID могло бы нарушить совместимость с уже существующим миром и интеграциями.

Поэтому репозиторий и видимое название относятся к линейке **LipatoS**, но технический ID остаётся `item-piles`.

Оригинальный Item Piles и эту сборку одновременно устанавливать не нужно — эта сборка заменяет его.

## Обмен валют у торговцев

В настройках торговца (Item Piles → Настроить → вкладка «Дополнительно», тип «Торговец») появилась галочка **«Обмен валют»**. После сохранения игроки увидят вкладку **«Обмен монет»** в окне этого торговца. По умолчанию обмен отключён.

Курс: **100 медных = 10 серебряных = 1 золотая**. Можно менять любые две из этих валют в обе стороны. Указывается количество монет, которые игрок отдаёт. Обмен без комиссии, только целыми монетами: например, для перевода в серебро нужна сумма меди, кратная 10. Остатки монет не теряются, потому что дробные обмены запрещены.

Баланс проверяется повторно на стороне активного ГМа, который исполняет обмен одним обновлением персонажа. Изменяется только кошелёк игрока, не кошелёк торговца. Для игроков нужен подключённый ГМ. Совместимость: Foundry VTT v14 + D&D 5e. Встроенная конвертация в листе персонажа не открывается — действует отдельный модуль блокировки обычной конвертации.

### Обновление интерфейса fix49

- Вкладка обмена стала компактной: уменьшены отступы, подсказки и высота блоков, исправлены цвета текста и сумм на тёмном фоне.
- В обмене используются оригинальные монеты из **LipatoS - Три валюты D&D5e** (`copper-v2.webp`, `silver.webp`, `gold.webp`); когда этот модуль не включён, предусмотрены запасные значки Item Piles.
- В торговле портрет расположен выше, ширина колонки изображения сокращена до 195px (примерно на 35% от 300px).
- Поиск и товары начинаются от верхней границы; строка «Покупатель» и его монеты закреплена внизу правого блока.

### Обновление fix50

- У изображений монет в обменнике и торговле убрана рамка.
- После выбора монеты для отдачи эта монета исчезает из списка получаемых (остаются две другие).
- В покупке/продаже монеты показываются через те же `copper-v2.webp`, `silver.webp`, `gold.webp`, что и в инвентаре «Три валюты D&D5e»; предусмотрен запасной источник, когда дополнение неактивно.
- В версии fix50 была добавлена первая реализация подсказок, впоследствии заменённая штатной карточкой D&D 5e в fix51.

### Обновление 3.3.5

- Переход с версий `3.3.4-rub-fixNN` на стандартную нумерацию: `3.3.5`, `3.3.6`, `3.3.7` и далее.
- В торговле сохранены штатные всплывающие карточки предметов D&D 5e из предыдущего исправления: срабатывают только на иконке и названии товара.
- Ссылка на манифест не меняется; Foundry продолжает обновлять тот же модуль с ID `item-piles`.

### Обновление 3.3.6

- В карточке товара торговца принудительно выбирается тёмная тема D&D 5e 6.0.6: внешний вид совпадает с подсказками инвентаря.
- Тёмная тема применяется только к полю иконки и названию предмета, не изменяя общий интерфейс магазина.
- Сохраняется штатное окно D&D 5e с полным описанием и характеристиками, без собственной перерисовки.

### Обновление 3.3.7

- В окнах подтверждения покупки и продажи используются изображения медных, серебряных и золотых монет, как в инвентаре LipatoS. Рамки вокруг монет удалены.
- При покупке в «Вы получите» отображается сам предмет, а при продаже в «Вы отдаёте» — предмет игрока и его количество вместо ошибочных монет.
- Расчёт цен, обратная сдача и передача предметов оставлены штатными; изменяется только отображение подтверждения.
