# История изменений

## 3.3.4-rub-fix49

- Сделан компактный интерфейс обмена валют; исправлена читаемость чисел и курса на тёмной теме.
- Вкладка обмена использует те же значки монет, что и инвентарь модуля «Три валюты D&D5e».
- Портрет торговца поднят, левая колонка уменьшена до 195px, список товаров начинается вверху.
- Строка «Покупатель» с кошельком закреплена внизу области покупки и продажи.


## 3.3.4-rub-fix48

- В настройки торговца добавлена галочка «Обмен валют» (включается мастером для каждого торговца).
- В окно торговца добавлена вкладка «Обмен монет» для игроков.
- Двусторонний обмен медь/серебро/золото по курсу 100:10:1 с проверкой целых сумм, наличия монет и разрешения на доступ к персонажу.
- Обмен выполняется через ГМа; штатная торговля не изменена.


## 3.3.4-rub-fix47

- Добавлена рекомендация модуля **LipatoS - Item Piles: D&D 5e** для миров D&D5e.
- Адаптер подключён через `relationships.recommends`, чтобы Foundry предлагал его установку без циклической обязательной зависимости.
- Ссылка на адаптер направлена на репозиторий LipatoS.
- Обновлён установочный архив основной сборки.

## 3.3.4-rub-fix46

- Текущая рабочая сборка перенесена в репозиторий **LipatoS**.
- Видимое название изменено на **LipatoS - Item Piles**.
- Версия рабочей сборки сохранена без изменений.
- Внутренний ID `item-piles` сохранён намеренно для совместимости с настройками, флагами, API Item Piles и другими модулями.
- Сохранены пользовательские доработки интерфейса добычи, торговцев, торговли и хранилищ.
- Сохранены русские подписи и дополнительные элементы интерфейса текущей сборки.
- Сохранено отображение валюты через отдельные изображения медных, серебряных и золотых монет.
- Сохранены доработки окон торговли, передачи предметов и валюты, а также редактирования валюты ГМ.
- Иконки трёх используемых валют оптимизированы без изменения разрешения 1254×1254 и без изменения логики модуля.
- Оригинальная лицензия MIT и сведения об авторе Item Piles сохранены.
